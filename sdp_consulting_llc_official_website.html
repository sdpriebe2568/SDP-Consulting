Deploy Website & Looka Logo Assets to GitHub

Target Repository: https://github.com/sdpriebe2568/SDP-Consulting

Save this single-file site as index.html inside your repository folder, copy your Looka logo assets from C:\Users\prieb\Documents\SDPConsultingLLC\Logo Files into an assets/ subfolder, and run these PowerShell commands: 

cd "C:\Users\prieb\Documents\SDPConsultingLLC"
mkdir assets -Force
Copy-Item "C:\Users\prieb\Documents\SDPConsultingLLC\Logo Files\*" -Destination ".\assets\" -Recurse -Force
git init
git branch -M main
git remote add origin https://github.com/sdpriebe2568/SDP-Consulting.git
git add index.html assets/
git commit -m "Deploy SDP Consulting LLC branded website and Looka logo assets"
git push -u origin main
Publish Live on GitHub Pages:

1. Open github.com/sdpriebe2568/SDP-Consulting/settings/pages.

2. Under Build and deployment → Source, choose Deploy from a branch.

3. Select branch main and folder / (root), then click Save.
